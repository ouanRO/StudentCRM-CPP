# Students Enterprise Manager 

**Student Enterprise Manager** is a C++ console application designed to manage graduated students affiliated with a company. It acts as a database and management tool to track qualified students, verify their graduation status, and schedule appointments.

##  Key Features
*  **Graduate Student Management:** Register, update, and search for student profiles with degree validation rules.
*  **Appointment Scheduling:** Book, update, and track appointments between students and company representatives.
*  **Data Persistence:** Save and load student and appointment records (via file handling or custom data structures).
*  **Filter & Search:** Easily filter eligible/graduated candidates and view upcoming appointments.

##  Tech Stack & Concepts
* **Language:** C++
* **Object-Oriented Programming (OOP):** Classes, Inheritance, Encapsulation, Polymorphism.
* **Data Management:** File I/O / Data Structures (Pointers, Vectors, Maps).
